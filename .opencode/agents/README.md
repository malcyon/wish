# Agents

| File | Purpose |
|---|---|
| `architect.md` | Plans missing subsystems or difficult multi-agent work without implementing the plan. |
| `backlog-auditor.md` | Audits authorized backlog evidence and returns bounded task briefs. |
| `changelog-writer.md` | Writes scoped release notes from verified repository changes. |
| `code-reviewer.md` | Reviews the root's scoped local commit without modifying the tree. |
| `deep-research.md` | Investigates unknown behavior that more specimens cannot settle. |
| `docs-reviewer.md` | Checks documentation against implementation and corrects scoped documentation. |
| `emulator-runner.md` | Runs specified existing drivers and preserves live experiment evidence. |
| `junior-dev.md` | Implements an already specified mechanism without making new design choices. |
| `qt-ui-specialist.md` | Implements approved Qt repairs with supplied wording, widgets and acceptance criteria. |
| `reverse-engineering.md` | Establishes byte layouts, parsers and driver behavior through bounded investigations. |
| `senior-analyst.md` | Plans a repair in existing code and identifies its implementation and focused proof. |
| `test-runner.md` | Executes serialized focused request bundles and bounded exact-SHA CI monitoring. |
