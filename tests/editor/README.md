# editor

Tests for the character editor in `editor/`, its binding and window, and how it behaves for each title.

| file | purpose |
|---|---|
| `test_dualclasscombo.py` | Checks that the editor's Class combo and a conversion agree on the class of a dual-classed Curse character. |
| `test_editor.py` | Checks the editor's file handling, binding and window headless: read-only fields, editing and writing back, items, effects, icons and the roster. |
| `test_hirelingopen.py` | Checks that a DOS or Amiga Pool of Radiance save whose party holds a Training Hall hireling opens in the editor with the hireling's own raw treasure share, and saves back with that share kept. |
| `test_leavebehind.py` | Checks the window that asks what to leave behind when a pack does not fit the C64: its approved heading and explanation, one window for every character who does not fit, a nonselectable joined-scroll heading over scrolls that can be ticked and show their spells, an accept button that agrees with the writer about what fits, and the ticks it hands back. |
| `test_membercondition.py` | Checks that opening a roster disk, a C64 save, a DOS folder or an Amiga disk records each member's condition and out-of-play flag from the port's own status and keeps the roster tail, and leaves the condition unread where the port stores none. |
| `test_miscbox.py` | Checks that the Misc box shows a member's condition as a word, with the out-of-play flag after it, and a Pool of Radiance member's damage from his roster tail, from every port's own status and tail, hides the damage line for the later titles, and that a save leaves the roster block's condition and tail as they were. |
| `test_namefitdialog.py` | Checks the window that asks for shorter character names when a C64 name is too long for DOS or the Amiga: its approved title and sentence, a row and a selected box for every character even when two share a name, the accept label the caller passes, an accept button that waits for every box to hold a name the writer takes, duplicates allowed, the names it hands back by position, and that a full party needs no scrolling at any realistic font. |
| `test_saveplan.py` | Checks that an unsaved DOS, Amiga or C64 edit reaches a conversion through `editor/saveplan.py`'s snapshot, that preparing one writes no file and moves no baseline, that a party with nothing edited snapshots the saved game it was read from, and that only the open slot's own folder, disk or `SAVGAM` file is answered from the snapshot. |
| `test_savepublish.py` | Checks that a Save As prepares a native copy or a conversion in memory, blocks one whose accounting names a dropped field and one whose output comes back holding a name or a value the sheet does not, blocks a destination named wrongly or standing in the save or the game data it reads, publishes it at a chosen image filename or into a new save folder with a backup of anything it replaced, and puts the destination back when publication or adoption fails. |
| `test_pertitle_ui.py` | Checks that the editor's race, item and caster tables change with the open title, that its map and tools glob the title asked for, and that a synthetic party exists for every title. |
| `test_saveasui.py` | Checks the split Open and Save buttons and their arrow menus, the destination section's visibility and fields per platform, every text for a stop or a failure wired to its exact `editor.saveplan`/`editor.files` exception, the stale-plan silent re-prepare, and the unsaved-changes guard shared with `close()`. |
