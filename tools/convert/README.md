# convert

Scripts for File > Convert: running every conversion direction, hashing what each one writes, and drawing the dialog.

| file | purpose |
|---|---|
| `convertamigadisks.py` | Drives `File > Convert...` offscreen and writes two POOLSAVE.ADF disks for loading in WinUAE, one from a C64 source and one from a DOS source, both specimens under `$WISH_SPECIMENS`. Needs `--disk` (Amiga Pool of Radiance disk 2); `--out` defaults to `dialog/` in the scratch directory; prints each conversion's report. |
| `convertamigatoc64.py` | Runs an `AmigaToC64` Pool of Radiance conversion through `EditorBinding.convert`, the dialog's own code path, with every `QMessageBox` silenced, and writes a JSON summary of the specimen hash and each output file's SHA-256. `--tree` runs it from another checkout; offscreen, no emulator. |
| `convertbytes.py` | Hashes, per file, the bytes every registered `File ▸ Convert…` direction writes, so two commits compare without an emulator: `--tree` measures another checkout, `--diff OLD NEW` names what moved, `--dump DIR` writes one conversion out. Run it in a detached worktree, not the working tree. |
| `convertdialogbuiltshot.py` | Draws the real, built `editor.convert.ConvertDialog` for the six directions and an Amiga source with three saved games onto one captioned sheet, from synthetic sources and the `por-amiga-outdoor` specimen. The counterpart of `convertdialogmockup.py`; needs Pillow, the DejaVu fonts and that specimen. |
| `convertdialogdrive.py` | Converts a DOS or C64 save to an Amiga save disk through `EditorBinding.convert`, recording the three `QMessageBox` calls instead of blocking, and writes a JSON report of the specimen hash, the popups and each written file's SHA-256. Takes `--specimen`, `--amiga-disk2`, optional `--disks` or `--c64-game`, and `--tree`; offscreen, no emulator. |
| `convertdialogmockup.py` | Draws the Convert dialog from the compiled `editor.ui_convert` shell in the four-row design, in all six directions, with every string not yet approved marked in the picture. A mock-up, nothing built; needs Pillow and the DejaVu fonts. |
| `convertdrops.py` | Reports what every registered `File ▸ Convert…` direction says it drops, over every specimen on this machine, calling `Direction.rehearse` as the dialog does and tallying each line against the specimens that reached it; `--reach` crosses each reader's neutral fields with its writer's declared list. Reads specimens from `$WISH_SPECIMENS`, C64 disks through `automap/gamedisks.py` and DOS archives through `tools/dos/dosbox.py`; writes only to a temporary directory. |
| `convertrun.py` | Converts a save through `File ▸ Convert…`'s own code path and boots the result: `--to c64` hands the `.d64` to `tools/c64/savecheck.py`, `--to dos` stages the files, loads them with `LOAD SAVED GAME`, walks, and has `ENCAMP ▸ SAVE` write the party back to diff. `--no-play` stops after the write; output goes to `--out` under the temp directory, never the player's disks. |
| `convertshots.py` | Renders every state `editor.convert.ConvertDialog` can reach to PNGs with `QWidget.grab()` offscreen, so each can be looked at without running anything. States that need the player's DOS save and game disks are skipped, with a line saying so, on a machine without them. |
| `convertsourcesheet.py` | Prints every field of every character the Amiga conversion rehearses from a C64 or DOS source, so the WinUAE screen has values to be read against. Takes SOURCE and `--disk` (Amiga Pool of Radiance disk 2); writes nothing. |
| `hallconvert.py` | Converts one DOS save twice, once with `goldbox.dos_savegame.current_area` patched to read `$49C5` indoors and once as shipped (`$49F2` always), and writes both C64 save disks to boot side by side. `--borrow GEO00` lends a mapless area the map its only caller leaves resident. |
| `rewritecensus.py` | Counts the fields of a DOS or Amiga record whose round trip through the editor's C64 record changes bytes, over every specimen and DOS save directory on this machine, saying for each whether the writer rendered more than one value for it and what `write_targets` says it sources it from; `--no-op` rewrites everything with nothing edited and counts what came back byte for byte, and `--unreachable` lists the fields the writer takes from a constant, a default, a zero or a derivation. Reads specimens from `$WISH_SPECIMENS` and the DOS archives through `automap/gamedisks.py`; writes nothing. |
