# icons

Scripts for combat icons and portraits: the correspondence tables between the DOS and C64 art, and the tools that build, check and draw them.

| file | purpose |
|---|---|
| `amigaicons.py` | Measures the Amiga Curse and Silver Blades combat-icon art against DOS's own: `--tables` reads the icon routine's three tables out of each executable's data hunk, `--art` compares every `CHEAD.TLB` and `CBODY.TLB` block with the same title's DOS `.DAX`, and `--census` checks the 21 Amiga specimens' icon fields name blocks the libraries hold. Opens every disk and executable read-only; write-up in `docs/199-amiga-combat-icons.md`. |
| `dosfigures.py` | Converts a DOS save folder into a C64 save disk on which every character keeps its own combat figure, then recomposes the six icons through `goldbox.iconparts.IconParts.dos_icon` and exits non-zero if the disk holds anything else. `--png` draws each DOS figure beside the C64 figure it converts to, `--mixed-png` the rows a small character wears from the large list. Disks come from `$POR_DISKS`, then `automap.paths.find_disks()`, and are never written; output goes under the temp directory. |
| `dosiconstage.py` | Sets a DOS party's combat-figure bytes so a conversion has something to convert: writes `icon_head`, `icon_body` and the `icon_colours` pairs into the `CHRDAT` files of a `--folder` and `--slot`, and nothing else. |
| `dosicontitles.py` | Decides whether one correspondence table can serve all three DOS titles: unpacks every block of each title's `CHEAD.DAX` and `CBODY.DAX` and compares it with Pool of Radiance's, and with `--code` reads each title's ICON menu wrap constants out of `GAME.OVR`. `--titles` adds Pools of Darkness, whose art is a different encoding and is counted rather than compared. Writes only what `--json` names. |
| `dosmixedicon.py` | Finds, or makes, a small DOS character whose `iconproposal.yaml` row names a C64 option only the large list has. `--census` reports every `.SAV` and `.CHA` under the DOS specimens already on such a row; `--stage` copies a party out and rewrites the `icon_head` and `icon_body` of its small characters, leaving `size` and the colours alone. |
| `dosnibbles.py` | Counts, in pixels over every block of `CHEAD.DAX` and `CBODY.DAX` at both sizes and both poses, which of a DOS part's two colours covers more of it, so the conversion's choice of the low nibble as the main colour can be judged. `--per-option` prints one line per `CBODY` option. |
| `dosportraitparty.py` | Opens every character's sheet in DOS Pool of Radiance and names the face drawn, by matching the frame against every `HEAD<n>.DAX` and `BODY<n>.DAX` block. `--c64` converts a C64 save disk into the slot through `goldbox.dos_codec.new_dos_save`; `--first K` swaps two of the six party entries in `SAVGAM<slot>.DAT` to reorder the marching order; `--probe` and `--sequence` press keys from a sheet or the map. |
| `iconcorrespond.py` | Lays the two ports' combat-icon option lists side by side and scores the pairing: renders every DOS option (`CHEAD.DAX`, `CBODY.DAX`) and every C64 option (`SPELLE64`, `SPELLN64`, `CHARPIC00` off `POOL3.D64`) to a 24x24 ink mask and scores each pair over a small alignment window. `--catalogue` prints one port's list as ASCII, `--show N` a DOS figure beside its best C64 match, `--png` a colour contact sheet under the temp directory. |
| `iconpoke.py` | Gives every character on a save disk a different combat figure, composed the way the game's own ICON menu composes one. Edits the disk in place, so point it at a copy under the temp directory. |
| `iconproposal.py` | Draws the DOS-to-C64 combat-figure table from `iconproposal.yaml` so each row can be judged: the DOS figure in its record's colours beside the proposed C64 figure and any alternatives. `--colours`, `--kind head` and `--size small` pick the sheets; `--title` picks whose own art both sides come from; `--markdown` writes the review document fresh; `--compare-c64` compares the C64 option art across the three titles' disks. Converts no save. |
| `iconproposal.yaml` | The DOS-to-C64 combat-figure tables (weapon, head, and EGA colour to C64 colour) as data: one row per figure with the C64 number, alternatives and a comment. Also holds a per-title `overrides:` section; `goldbox.iconparts.dos_icon_tables` reads it by title, but no caller passes a title yet, so an override reaches the proposal document and not a conversion. Edited by hand; committed because it is our judgement, not the game's data. |
| `iconredrawn.py` | Draws the two combat-figure options Silver Blades re-drew, three figures per row and both poses, scaled up: the option as Pool of Radiance draws it, as Silver Blades draws it, and the C64 figure the row names today. Reads the mapping from the YAML and measures which options differ at run time. Writes one self-contained HTML file under the temp directory; it holds the game's art and is never committed. |
| `iconreverse.py` | Draws the C64-to-DOS combat-figure table from `iconreverse.yaml` so each row can be judged. `--coverage` says how each row is decided (forced by the forward table, a pick among merged DOS options, or a C64 figure DOS has none of), `--census` reads every combat icon on the player's C64 disks back into menu choices through `IconParts.recognise`, and `--markdown` writes the review document fresh. Pictures go under the temp directory. |
| `iconreverse.yaml` | The C64-to-DOS combat-figure tables (large and small weapon and head, and C64 colour to DOS colour pair) as data, keyed by the C64 option; each size section is a complete list because large and small weapon 3 are different drawings. Read by `goldbox.iconparts.c64_icon_tables`; its `overrides:` section is not applied yet, because no caller passes `c64_party` a title. Edited by hand; committed because it is our judgement. |
| `iconrowproof.py` | Stages one combat-figure row into a DOS party, converts it through `goldbox.dos_codec.convert_save`, and reads each arriving C64 icon back into the menu choices that drew it, proving a row reaches a converted character. `--control` converts again with the title's `overrides:` ignored; `--home` reads each icon back into DOS with and without the title. Copies the save or specimen into a staging directory under the temp directory and never edits in place. |
| `iconsheet.py` | Renders every icon the program ships at the sizes it is seen at, through the same painting code the map and the roster use. |
| `iconswing.py` | Finds where a combat icon's second nine screen codes go: in a fight it drives `Session.melee_turn` and arms VICE load checkpoints on the save's own codes and on the bitmaps `COM.PREP` expands them into, scoring all eighteen expanded glyphs against `CHARPIC00`. `--camp` reads the ENCAMP > ALTER > ICON screen instead. Findings are in `docs/186-ready-and-action.md`; output goes under the temp directory. |
| `inkcount.py` | Counts an icon's ink pixels and how many connected pieces it comes apart into, at the size the program draws it: the two numbers `docs/136-condition-badges.md` grades every condition badge by. |
| `portraitdraw.py` | Finds which C64 title's character sheet draws a portrait at all: locates each overlay's load address by scoring its jump targets, the loader's two entries by their code, and `ANIMATE`'s five draw entries from the title's own load-address table, then counts the calls to each over every file on every side. Works on a title nobody has mapped. |
| `portraitmenu.py` | Re-derives the 26 numbers `goldbox/portraits.py` stores as `POOL_OF_RADIANCE_MENU` (14 head and 12 body art ids in menu order) from the C64's `GEN` and DOS's `START.EXE`, and prints each as a Python literal. `--check` compares both readings with the stored block and exits 1 on any disagreement; nothing but the ids leaves either file. |
| `portraitshot.py` | Photographs a DOS character's sheet portrait under DOSBox and says which art it drew, by matching the pixels against every `HEAD<n>.DAX` and `BODY<n>.DAX` block from the player's own files. `--rewrite` puts a slot's records through the writer and leaves the saved game alone, `--template` does the opposite, and `--words 49FF=3` patches saved-game words. Stages its own copy of the game tree and opens no window. |
