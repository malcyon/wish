# amiga

Scripts for the Amiga ports: reading their disk images and executables, disassembling them, and driving them under FS-UAE and WinUAE.

| file | purpose |
|---|---|
| `amiga68k.py` | Reads a Gold Box Amiga executable: lists its hunks, finds who references a file offset, and disassembles a range with SAS/Lattice `jsr d16(a4)` jump-table calls and `RELOC32` operands resolved and C strings quoted. Needs `capstone`. See `docs/165-amiga-savegame.md`. |
| `amigabackstab.py` | Reads each Amiga title's backstab multiplier, gate, record bytes, clamp and damage byte out of its own executable (needs `capstone`); `docs/225-the-dos-backstab-multiplier.md`. |
| `amigabladesjournal.py` | Answers Amiga *Secret of the Silver Blades*'s journal prompt so a session can be driven past the party menu, printing only `answered` or `no challenge on screen`; reads the answer tables from the separate code-wheel repository named by `$WISH_CODEWHEEL` or the `codewheel` entry in `gamedisks.yaml`, and types through `amigadrive.py`. |
| `amigacontainercheck.py` | Checks that the Amiga saved game `goldbox.amiga_savegame.new_por_savegame` builds carries the source C64 save's own square, facing, clock, area and resident map, printing which fields differ from the shipped `savgamA.dat`; exits 0 when every container matches its source, 1 when one does not, 2 when there is nothing to check. C64 saves come from `$WISH_SPECIMENS`, Amiga disks from the registry's `amiga` entry; opened read-only, and only `--out` is written. |
| `amigacursewheel.py` | Answers Amiga *Curse*'s code-wheel prompt so the title can be driven unattended, printing only `answered` or `no challenge on screen`; reads the answer from the separate code-wheel repository named by `$WISH_CODEWHEEL` or the `codewheel` entry in `gamedisks.yaml`, and presses it through `amigadrive.py`. A no-op on the other titles. |
| `amigadrive.py` | Types at an Amiga game running under WinUAE in the Windows VM from Linux (`keys RET L S A V E SLASH RET`) and grabs the guest's screen; `NP0` to `NP9` are the numeric keypad that walks a party in Amiga Curse and Silver Blades. Takes no lane claim, and every call is refused without `--holder`. Opens no window on the host. |
| `amigaenum.py` | Names an Amiga Gold Box enumeration from the routine that draws it: finds the sites where a record byte is scaled and used to index a `char *` table, prints the strings a table holds, and lists a `GLIB` text library's blocks. |
| `amigaglobal.py` | Finds every instruction that touches a SAS/Lattice small-data global, and every caller of a routine, in Amiga *Curse* and *Silver Blades*, by scanning for the displacement word and decoding a short window around each hit; use it where `amiga68k.py refs` finds nothing. Needs `capstone`. |
| `amigaindexedrefs.py` | Finds the ways an Amiga executable reaches a record byte that `amigarecordrefs.py`'s displacement search cannot see -- `d8(An,Xn)` by raw displacement byte, a `lea d16(An)` base within a chosen reach below the byte, a register rebased by `lea`/`adda` and then used, an index register loaded with a constant, and a wider access from below -- across every CODE hunk; every hit is a lead to read. Needs `capstone`; reads only. |
| `amigalaterproof.py` | Puts a party converted by `goldbox.amiga_later.write_later` in front of the running Amiga *Curse* or *Silver Blades* and diffs the engine's resave against ours block by block, masked by the writers' declared lists and exiting non-zero on any difference outside them. `build` is `amigalaterwrite.py --into` plus `--first <name>`, which moves a character to the front of the party. Inputs read-only, `--out` required; see `docs/203-a-converted-later-amiga-party-in-the-running-game.md`. |
| `amigalaterslot.py` | Puts a saved game our code wrote in front of Amiga *Curse* or *Silver Blades*: reads a slot off a disk image, rebuilds the container through `goldbox.amiga_savegame` with one visible edit (`--rename n=NAME`, `--keep n`, `--strip-items n`), and writes it to another slot on `--out`. The input image is read-only. |
| `amigalaterwrite.py` | Converts a C64 or DOS party into Amiga *Curse* or *Silver Blades* records through `goldbox.amiga_later.write_later`, printing one line a character (block length, item and effect counts, chain heads), with `--compare` against the Amiga's own record of the same person and `--into ... --out` to rebuild a copy of a disk with the party in a save slot. Sources read-only. |
| `amigalayonhands.py` | Reads where Amiga Curse, Silver Blades and Pools of Darkness keep a paladin's lay-on-hands use from each executable (needs `capstone`): the heal call's effect id, duration, value and flag, `add_affect`'s node stores, the sheet gate's `find_affect`, the effect handler table and whether the id has a slot in it, and the cure timer beside it, the expiry routine's scale table and duration subtract, and with `--dispatch` every caller of the handler dispatcher classified by where its id comes from; `docs/231-where-lay-on-hands-lives.md`. |
| `amiganamespaces.py` | Finds the routine each Amiga title uses to strip a fixed set of characters (a space among them) out of a name, says which call sites copy the result back into a character record and whether unconditionally, finds any in-place swap of a space for `$FF`, models what Pool of Radiance's save and creation do to a name, and counts the names with spaces on the player's disks and in the specimen tree. Read-only; needs `capstone`. |
| `amiganodefields.py` | Says which bytes of an Amiga *Curse* or *Silver Blades* heap node the game's own code touches: `pool` lists every instruction naming the node pool's descriptor and whether it allocates or frees, and `fields` prints every displacement read or written through a node reached from a chain-head load. It ignores control flow, so a reported displacement has to be read and an unreported one is unreachable. Read-only; needs `capstone`. |
| `amigaportraitmenu.py` | Re-derives `goldbox/portraits.py`'s `AMIGA_POOL_OF_RADIANCE_MENU`, the Amiga's fourteen head and twelve body art ids, off the player's Amiga disks and checks each id against `head.dax` and `body.dax`. `--check` exits 1 if the disks disagree with the stored block, `--art` is the body-art census, `--montage` draws both ports' menu bodies, `--palette` prints the thirty-two `0RGB` words the boot code copies. |
| `amigaportraitresolve.py` | Settles whether the Amiga Pool of Radiance record's portrait bytes at `0x0BD`/`0x0BE` hold a creation-menu position or an index into `body.dax`, from the `RELOC32` references to the menu tables in `/program`. `--check` exits 1 if the executable no longer has that structure, `--out-of-range N` prints what a value past a table's end would fetch. Reads the player's `.adf` images, loose or zipped; writes nothing. See `docs/188-the-sheet-portrait-per-title.md`. |
| `amigarecordrefs.py` | Finds every instruction in an Amiga executable that reaches a character record byte (`move.b $145(a0), d0` and its kin), by the displacement word, decoding each candidate from its own start; a hit is a candidate until the listing is read. `amigaglobal.py` does the same for a small-data global. Searches every CODE hunk and prints each site's hunk; needs `capstone`. |
| `amigarecords.py` | Pulls the twenty-one Amiga *Curse* and *Silver Blades* character specimens out of their disk images, read-only: the eleven `SAVE/*.guy` pregens on Curse disk 1 and the two saved games whose parties are found by record signature. `amigasaves.py` does the same for Pool of Radiance. `tests/amiga/test_amiga.py` calls `extract()` when the environment names no directory. |
| `amigasavecheck.py` | Reads an Amiga saved game (Curse, Silver Blades or Pool of Radiance) through the map its own save routine writes and checks the parse against the record signature scan, `$503E`, `$5012` and the file length. `--adf` reads every `savgam*` off a disk image, in the root or a `save` drawer; `--sweep` prints one table of which variable words are ever non-zero, grouped by `$5012`. Read-only. |
| `amigasaves.py` | Pulls the twenty Amiga *Pool of Radiance* character specimens out of their disk images with their `.itm` and `.spc` siblings: six in the `save/` drawer of disk 1 and fourteen on the Curse save disk. Refuses to overwrite if two images disagree about a file; the disks are read-only. `tests/amiga/test_amiga.py` calls `extract()`. |
| `amigashots.py` | Presses keys at an Amiga game under WinUAE one at a time and saves a numbered PNG of each, cropped to the emulator's own screen; `crop` crops a grab somebody else took. The client area is found from WinUAE's status bar with its height from `goldbox-a500.uae`, and a desktop with no such bar is reported rather than cropped to a guess. Opens no window on the host. |
| `amigatarget.py` | Reads a running Amiga Gold Box title through `automap/amiga.py`: `verify` checks the per-title address table against the executable on the player's own disk with no emulator at all, `locate` measures the data hunk's load address in the running machine, `fix` says where the party is standing, and `geo` dumps the resident 1024-byte map and names it against a `GEO.GLB` library. Needs a WinUAE lane claim for everything but `verify`, and takes neither the claim nor the VM lease itself. |
| `amigathac0.py` | Reads Curse's and Silver Blades' THAC0 tables and checks both recompute loops in the player's own Amiga executables, showing why the guarded loop stores 39 for a level 1--5 magic-user and the import/training loop stores 40. |
| `amigaunpack.py` | Reads a Gold Box Amiga loader's routine that expands a packed DOS record and prints the source-to-destination map it writes, so a shift map comes from instructions rather than from specimens. |
| `amigazerowords.py` | Counts how many of the bytes a converted Amiga Pool of Radiance saved game writes as zero an area nobody has saved in could fill: builds a container through `goldbox.amiga_savegame.new_por_savegame` and asks the game's twenty-nine `ecl.dax` blocks what they do with each word, using `tools/areas/eclcensus.py`'s decoder. `--engine` adds `/program`'s own accesses, `--dos` adds DOS containers. Prints no string of the game's as text; writes only the JSON asked for. |
| `fromamigapor.py` | Builds a C64 *Pool of Radiance* save disk (`--to c64`, the default) or a DOS save folder (`--to dos`) from an Amiga save slot, the mirror of `toamigapor.py`. Reads the game's `save` drawer or a `POOLSAVE` disk's root; `--to c64` needs the player's own C64 sides, `--to dos` needs `--game` naming the DOS game folder. `--report` prints provenance, `--sheet` prints the party as the C64 `VIEW` screen does, and `--against` compares that with a `tools/c64/savecheck.py` log. The `.adf` is read-only. |
| `fsuaebuildclang.sh` | Builds the patched FS-UAE (`grahambates/fs-uae`, branch `remote_debugger_barto`) with clang inside a clean container with the source at `/src`; installs packages with apt-get, so never run it on the host. Logs go to `/tmp`, and it exits with make's status. |
| `fsuaebuildcontainer.sh` | Builds the patched FS-UAE (`grahambates/fs-uae`, branch `remote_debugger_barto`) with gcc inside a clean Ubuntu 24.04 container with the source at `/src`; installs packages with apt-get, so never run it on the host. `fsuaebuildclang.sh` is the clang version. |
| `fsuaegdb.py` | Reads a running Amiga in a patched FS-UAE over its GDB-remote port: `probe` times reads and shows the machine never halts, `locate`/`fix`/`geo`/`dump` read the game, `automap` runs the shipped automapper, `session` holds one connection open and takes commands from a file, `launch`/`stop` start and tear down a silent offscreen emulator. |
| `fsuaegdbprobe.py` | The standalone GDB-remote client for the patched FS-UAE (the `Gdb` class) and a probe of whether a memory read returns while the machine runs: takes PORT (default 6525), reads while halted, continues, then polls `VHPOSR` and a 1 KB block twelve times, timing each. `RAW=1` prints raw replies. `fsuaegdb.py` is the command line built on `automap/amiga.py`. |
| `fsuaepor.py` | Drives Amiga *Pool of Radiance* in the stock `fs-uae` inside an instance-pool slot, a second emulator the Amiga tools can use alongside WinUAE: `stage` copies a disk 1, overwrites chosen records' name fields and can drop slots for room or add a blank `POOLSAVE`; `serve` runs a silent `Xvfb` and `fs-uae` on the slot's display with the floppies written back in place, and `--floppy` boots any other title's images; `keys`, `shot` and `names` press keys, grab the screen and read every slot's names back. `curse-stage` stages Curse's two disks and `wheel` answers its code wheel through the private repository's reader, which does not yet accept an FS-UAE capture. The capture helpers count blank character cells in a party-panel or sheet row. Inputs read-only. |
| `fsuaeprobedrive.py` | Drives the patched FS-UAE over its GDB socket for 110 seconds: reads `VHPOSR` and a 1 KB block every 1.5 s, takes Xvfb screenshots and sends keys at fixed times so a screenshot proves the machine advanced, then times reads of 2 to 128 KB. Takes PORT, `--display` and `--shots`; uses `fsuaegdbprobe.py`'s `Gdb`, and the emulator must already be running in a private Xvfb. |
| `fsuaeruncustombuild.sh` | Starts the FS-UAE built from source in a private Xvfb (display :78, debugger port 6528, base directory under `<tmp>/wish/fsuaeruncustombuild/`) and times its GDB-remote reads while the Amiga runs, using `fsuaegdbprobe.py`'s `Gdb`. Kills the emulator's process group on the way out; check nothing else is on that display and port. |
| `fsuaerununpackaged.sh` | Starts the prebuilt, packaged FS-UAE, whose path is the script's one argument, in a private Xvfb (display :79, debugger port 6529) and times its GDB-remote reads while the Amiga runs: the same test as `fsuaeruncustombuild.sh` against the packaged binary. Check nothing else is on that display and port. |
| `goldbox-a500.uae` | The WinUAE machine a Gold Box Amiga title boots on in the Windows VM: a stock A500 with Kickstart 1.3, both drives turbo and `use_gui=no`, loaded with `winuae64.exe -f` and overridable line by line with `-s`. Binds F11 to `SPC_ENTERDEBUGGER`, the only way into WinUAE's debugger on Windows; `joyport1=none` frees the keypad that walks a party, and `sound_output=interrupts` because `none` deadlocks Silver Blades. Paths are the guest's; no game data. |
| `installfsuae.py` | Fetches the pinned `uae-dap` npm tarball over HTTPS, checks its SHA-256, unpacks only the patched FS-UAE from it into a `uae-dap-<version>` directory under a per-user one (or under `--into DIR`, replacing nothing else there) and prints its path and how to point `fsuaegdb.py launch --fs-uae` at it; a second run does nothing. |
| `m68dis.py` | A 68000 disassembler that refuses to guess: a word it does not recognise prints as `dc.w $xxxx`, never as the nearest instruction that fits, and every field is checked before a mnemonic is emitted. Branches and PC-relative operands print the address they reach; `--refs ADDR` reports every instruction pointing at one address. Reads a raw binary at file offsets and does not parse AmigaDOS hunks, so give `--offset`/`--length` inside the code hunk. See `docs/50-experiments.md`, "The 68000 disassembler". |
| `m68discheck.py` | Checks `m68dis.py` against capstone over a real Amiga binary, in both 68000 and 68020 mode, and accounts by name for every word `m68dis` refused. The binary is not in this repository and is a required argument. |
| `podimportmap.py` | Reads Amiga *Pools of Darkness*' own *Secret of the Silver Blades* importer, the routine at file offset `0x026000` of `/Pools of Darkness` on disk 1, and prints it as a field map against `goldbox.amiga_port.SILVER_BLADES_DELTAS`. `--check` compares all of `goldbox.amiga_pod`'s offsets with the instructions that write them, `--thac0` prints the attack table the engine indexes by class level and checks the arithmetic against every `.pc` on the disks, and `tests/amiga/test_podamiga.py` runs both. Takes the build most disk-1 images agree on and prints the counts; read-only except `--json`. Needs `capstone`. |
| `podpcregions.py` | Decodes the tail of an Amiga *Pools of Darkness* `Save/NAME.pc`, the item records and effect nodes past the 404-byte character record, reading an item's twenty bytes as the later-Amiga item node through `goldbox.amiga_port.AMIGA_LATER_ITEM_SHIFTS` and an effect's ten as DOS's five payload bytes with the pad at 1 and the chain at 6. Opens the disk images read-only and prints no string of the game's. |
| `podsavegame.py` | Reads the Amiga *Pools of Darkness* `Save/SavGam<L>.pty` through the map its own save and load callbacks lay out -- the byte-wide variable array, the six-byte square struct, the two mode bytes, the two map words, the `u16be` party count and the inline `.pc` payloads, whose map lives in `goldbox/amiga_savegame.py` -- and checks every slot on the player's disks parses, rebuilds byte for byte and comes to 10,828. `--vars` prints the ECL variables the engine's own code names against DOS's own census, `--vault` checks the `Vault<L>.DAT` beside each slot; `--check` exits 1 on a disagreement. Read-only; `--vars` needs `capstone`. See `docs/124-amiga-port.md` §1.20. |
| `porboat.py` | Puts an Amiga *Pool of Radiance* party in front of New Phlan's harbour master to make an outdoor saved game: edits eight bytes of the shipped engine-written saved game (the square to `(11, 2)` facing north, `$4AA7` to 255) and lets the engine compute the rest. It never stages `$4AC4`, the destination, because New Phlan's entry-4 prologue resets it. The input image is read-only and `--out` is required to write one. |
| `porslot.py` | Copies an Amiga *Pool of Radiance* save slot into another slot on the same disk, the only caller of `goldbox.amiga_savegame.write_por_slot` outside the tests. The party is read through `goldbox.amiga_savegame.read_por_slot` and `goldbox.dos_codec.to_neutral`, so it crosses the neutral record a converted party would and what cannot cross is printed. The input image is read-only and `--out` is required. |
| `porslotdiff.py` | Diffs two Amiga *Pool of Radiance* save slots field by field, to show what the engine changes about a party our code wrote: put a slot on a disk with `porslot.py` or `toamigapor.py`, boot, load, camp and save to another slot. Also counts NUL item display lines on each side; `--drawer ''` reads slots from the root of a save disk. Writes nothing. See `docs/124-amiga-port.md`, `docs/191-the-amiga-save-disk.md` and `docs/182-amiga-por-in-the-running-game.md`. |
| `toamiga.py` | Writes a C64 party out as Amiga *Pools of Darkness* `Save/NAME.pc` files, one per character, ready to drop into a disk 3 `Save` drawer. Goes through `goldbox/neutral.py`'s `NeutralCharacter`, so it reads any of the six C64 titles, and prints what cannot cross rather than dropping it quietly. The C64 disk is read-only. |
| `toamigapor.py` | Writes a C64 or DOS *Pool of Radiance* party into a save slot on an Amiga disk, through `goldbox/neutral.py`'s `NeutralCharacter` and `goldbox.amiga_por.write_por`, and prints what cannot be converted; refuses a Curse or Silver Blades party. `--container` names the slot whose saved game is copied around the party; `--save-disk` writes the 880K `POOLSAVE` floppy a player is handed, with the slot in its root and no game code. Exactly one of `--out` and `--save-disk` is required; the input image is read-only. See `docs/191-the-amiga-save-disk.md`. |
| `winuae-lanecheck.ps1` | Proves that one driver of WinUAE cannot destroy another's run: runs on the Windows guest against whichever copy of `winuae.ps1` it is pointed at, with rounds for a second driver's `stop`, `key` and `start`, simultaneous `claim`s and a holder re-asserting its own lane. Fails when no hijack round actually raced, and resets the lane through the scheduled task, never by killing a process by name. |
| `winuae-send.ps1` | Types into WinUAE's debugger console from a script and reads the console back as text (`AttachConsole`, `WriteConsoleInput`, `ReadConsoleOutputCharacter`); runs on the guest in session 1. The read path is `S <file> <addr> <n>` here plus an `scp`. Every path out ends `--- exit N token=...` with the caller's own token, and no error may reach PowerShell's host: errors are terminating and a `trap` turns what escapes into `died: ...` and `--- exit 7`. |
| `winuae-sendcheck.ps1` | Sends twenty eight-line batches through `winuae.ps1 send` and counts the ones that died without a verdict or lost a log line: takes the lane, starts an emulator with a console if none is running and presses F11 once. Runs on the guest against whichever driver and injector it is pointed at, puts the injector back and resumes the emulator whatever happens, and stops only an emulator it started. |
| `winuae.ps1` | Starts, stops, raises and drives WinUAE on the Windows guest through `winvm ssh`, every action through an Interactive scheduled task because `winvm ssh` lands in session 0 and the VM's screen is session 1. `key 7A` presses F11 to open the debugger, `roms` points WinUAE at `C:\Amiga\Kickstarts` and rescans without a GUI, and `claim -Holder <id>` makes the VM single-tenant: every other action refuses a caller who is not the holder, and `stop` refuses a `winuae64` its receipt does not describe. Every action reports `ok` or `fail`, and every refusal carries the `-Override` line that clears it. See `docs/143-winuae-debugger.md`; `winuae-lanecheck.ps1` is the proof. |
| `winuaepipe.py` | Talks to a running WinUAE through its own named pipe, `\\.\pipe\WinUAE`, which reaches the debugger's command parser with no F11, no console window and no halt: `probe` reads the Amiga's first bytes, `send` runs debugger commands, `ticker` proves the machine is still executing by Exec's own counters, and `time` measures what a poll costs. Reading commands only; anything that could open a debugger console is refused. Needs a WinUAE lane claim and takes neither the claim nor the VM lease itself. |
| `winvmguest.py` | The agent guest's `winvm`: drives the Windows guest over one ssh endpoint with the guest's own key and a pinned host key, with no libvirt. `ssh`, `scp` and `shot` take the desktop `winvm`'s arguments, so the tools above run unchanged; `ps` sends PowerShell as `-EncodedCommand`, `put` and `get` copy either way, `shot` grabs the console session through a one-off Interactive scheduled task and fetches the PNG on the same ssh call, and `status` and `lane` read the WinUAE lane from `winuae.ps1 status`. Refuses `acquire`, `release`, `up`, `down`, `save`, `promote`, `revert` and `guest-setup`. Installed as `/usr/local/bin/winvm` by `ansible/roles/agent-winvm-access`; `docs/219-the-agent-sandbox.md`. |
| `winvmsettle.py` | Waits for the Windows VM's screen to stop changing and keeps the last grab: grabs `winvm shot` every couple of seconds until two consecutive grabs are byte for byte the same, and a run that never settles inside `--limit` keeps the last grab and says so. Replaces a fixed `sleep` between keystrokes into an Amiga game. Opens no window on the host. |
