# suite

Scripts that run and check the test suite: the whole-suite run that gates a push, the generated test party, the rules check, the sys.path census and the diagnostic pytest plugins, loaded on demand with `-p` rather than wired into `pyproject.toml` or `tests/conftest.py`, that measure and reproduce the race behind a flaky conftest guard test.

| file | purpose |
|---|---|
| `conftestflake_analyze.py` | Summarises the logs `conftestflake_probe.py` writes: merges every worker's CREATE and DELETE events for the two probe files `tests/test_conftest_state_guard.py` writes and removes, and says whether and for how long their lifetimes overlapped. |
| `conftestflake_force_group.py` | Diagnostic pytest plugin that applies `xdist_group` to both tests in `tests/test_conftest_state_guard.py` at collection time, without editing that file, to check whether grouping puts them on one `-n auto` worker. Runs `tryfirst` so it precedes xdist's own hook. |
| `conftestflake_probe.py` | Diagnostic pytest plugin that logs the timestamp and worker id of every appearance and disappearance of the throwaway probe files `tests/test_conftest_state_guard.py` writes, without changing that file. `conftestflake_analyze.py` reads its log. |
| `conftestflake_windows_repro.py` | Pytest plugin that forces the collection race deterministically: it deletes a chosen sibling under `tests/` after `tests/`'s collect report (`ISSUE522_MODE=force`) or leaves it (`control`), and logs both arguments of `samefile_nofollow` and any exception. `.github/workflows/flake-measure-conftest-guard.yml` drives it on Windows. |
| `pathleak.py` | Lists which `tools/` scripts leave `tools/` on `sys.path` after import, and which of those capture the name `wish` when run as a file. |
| `rulescheck.py` | Checks where every rule and quotation of the pre-split `CLAUDE.md`, read from git, ended up in `.claude/rules/*.md` and `docs/160-why-these-rules.md`: a missing quotation of Donald's is an error, a missing bolded imperative a prompt to check whether it was reworded or dropped. |
| `suiterun.py` | The one whole-suite run before a push: fetches origin and rebases onto `origin/main`, then in a detached worktree runs the full suite, a no-data pass (every `tools/` module imported in a fresh interpreter, then the test files that ask for game data), `ruff` and `genui.py --check`, and writes the `~/.cache/wish/testrun/<sha>.green` marker `.claude/hooks/check-push-tested.py` reads. |
| `testparty.py` | Generates the six-character test party of `docs/119-test-party.md` from code alone, with no emulator or game bytes; `--rolls max`, `min` or `seeded`, `--records DIR` writes `.CHR` exports and `--disk PATH` puts all six on a copy of the player's save disk, never the original. |
| `testpartyrun.py` | Boots a `testparty.py` disk in a pool slot and reads all six character sheets off the screen, the third gate of `docs/119-test-party.md` section 6; stages the save beside symlinks to the player's own sides, photographs each sheet and writes one JSON line per event to `run.jsonl`. |
