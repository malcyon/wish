# registry

Scripts that say where things are and who holds them: the game disks, the specimen tree and its backups, the emulator instance pool and the scratch directories.

| file | purpose |
|---|---|
| `gamedisks.py` | The registry of where the game disks and saves are (`#212 (One registry for where the games are, instead of seven searches in six files)`) — this machine's `gamedisks.yaml` (gitignored, copied from the committed `gamedisks.yaml.example`, which is the whole registry) and the environment variable that wins over it; with no `gamedisks.yaml` it stops with a one-line message saying to copy the example. Run with no arguments, it prints one row per entry: the variable, which layer answered, the path, and whether it is actually there — turning "103 skipped" into a question anybody can answer in a second. |
| `instance.py` | The VICE instance pool: six resources per slot (two monitor ports, a command port, an X display, a work directory and a private `vicerc`), held by one lease. The lease is an `fcntl.flock`, so the kernel frees a crashed run's slot with no cleanup script. Nothing here ever kills a process by name — teardown is `os.killpg` on the group *this slot* started. `status` also says whether a held slot is idle -- how long since anything but the lease was written into it, and whether one process is holding more than one slot, which is the actual leak -- and it finds that out by reading mtimes and asking for a process group, never by probing a monitor an agent is using. `claim -- <command>` catches `SIGTERM` and tears its process group down before the wrapper itself is allowed to exit, so a shell `timeout` wrapped around it actually bounds the run instead of only killing the wrapper (`#381 (A shell timeout wrapped around tools/registry/instance.py claim exits without stopping the VICE run it wraps)`). |
| `scratch.py` | Where a tool writes what it produces: `scratch_dir("dosbox", "shots")` is `<tmp>/wish/dosbox/shots`, one directory per tool and never one named for a ticket, and `cache_dir("testrun")` is `~/.cache/wish/testrun`, for the few things that must survive a reboot, such as the marker a green suite run leaves for the push hook. Neither function creates anything; `ensure(path)` makes the directory and is called immediately before the first write, so `--help` and a refused argument leave the disk alone. A tool imports it with `from tools.registry import scratch` after putting the repository root, never `tools/` itself, on `sys.path`. `tests/test_scratch.py` covers it. |
| `specimenbackup.py` | Counts the copies of the specimen tree and makes one more. `audit` hashes every file under a directory or inside an archive and reports which of the tree's recorded contents have a second copy anywhere -- by SHA-256, never by filename, so a file edited since does not count and one the run called something else does. `.tar.zst` is read through `zstd`, which is what the hourly snapshot of the deleted scratch directory was. `archive` writes the whole tree to one file, refusing a destination inside the repository, one that already exists, and a tree that does not match its own manifests. `verify` reads an archive back against the live `provenance.toml` files and says whether it could put every specimen back. `#249 (Build a DOS party from creation and level it ourselves, so DOS measurements rest on records we watched being written)` step 5, "somewhere durable to keep it". |
| `specimens.py` | Manages `$WISH_SPECIMENS` (default `~/wish-specimens`), the tree of DOS, C64 and Amiga records this project watched being written, outside the repository. `add` copies a save in and writes a `provenance.toml` naming who made it, how, and what was done to it, then makes every file and the specimen's own directory read-only; `check` verifies each file's SHA-256 against that manifest and flags any file in the tree no `provenance.toml` accounts for; `list` shows what is there. Seeded for `#249 (Build a DOS party from creation and level it ourselves, so DOS measurements rest on records we watched being written)` and `#246 (Nothing tells an engine-written DOS record from one edited with Gold Box Companion, and conclusions already rest on edited ones)` with the eight characters `#84 (Roll a gnome in DOS and read the two innate effect ids nobody has seen)` rolled from creation. `amiga` in `PLATFORMS`, and the `<title-slug>-<platform>` directory naming that lets more than one title share a platform, are `#343 (The specimen tool cannot add an Amiga specimen, so three have been hand-written)`. |
