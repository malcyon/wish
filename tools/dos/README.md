# dos

Scripts for the DOS ports: DOSBox and the drivers built on it, overlay and record readers, and the save and party tools.

| file | purpose |
|---|---|
| `backstab.py` | Reads the backstab gate, multiplier and regain helper out of DOS Curse, Silver Blades and Pools of Darkness by instruction structure; `docs/225-the-dos-backstab-multiplier.md`. |
| `daxls.py` | Lists the blocks of a DOS Gold Box `.DAX` container with id, offset, sizes and image dimensions; `--dump` writes one unpacked block and `--png` draws an image block as EGA. Layout in `docs/168-dos-dax-and-combat-icons.md`. |
| `dosabilitypair.py` | Shows which byte of a DOS ability pair the engine treats as in force: `sites` and `census` read `GAME.OVR`, `stage` writes unequal pair bytes for a boot, `read` prints every pair. Archives are read only; `docs/204-the-dos-ability-pair.md`. |
| `dosaddchar.py` | Drives DOS Pool of Radiance's ADD CHARACTER TO PARTY with two `.CHA` files that differ only in the identity byte at `0x0AB` (`--ident`, or `--writer` for our writer's value) to test the duplicate check, reading the resulting `CHRDAT` files as ground truth. |
| `dosaffectreads.py` | Reads, per effect id and per title, which bytes of a DOS effect node the engine's handlers, `find_affect` callers and chain walkers read, which readers read byte 3 or 4 of every node, what a readied magical item writes, and Pool of Radiance's strength-item value byte; `docs/230-who-reads-a-dos-effect-node.md`. |
| `dosarraywidth.py` | Reads how wide an array inside a DOS character record is from an overlay's instructions with `capstone`, no emulator or specimen; `--family` runs all four titles. An empty result is not proof, and 1-based loops need `dosrecordloops.py`. |
| `dosbox.py` | Runs a DOS Gold Box game in DOSBox on a private X display, unattended: keys through `xdotool`, a 320x200 framebuffer capture, and the save files DOS writes as ground truth. Refuses a display already in use and a one-colour screenshot. |
| `dosboxx.py` | The DOS debugger harness: `dosbox.py`'s session on a DOSBox-X built `--enable-debug=heavy`, giving memory reads and writes, `BPM` watchpoints, code breakpoints, registers and single-stepping through a log file. Uses displays :90-:105. |
| `dosbyteimm.py` | Lists which constants a DOS overlay stores into, or compares against, one character-record byte (`--offset`), which is what names a field where `dosfieldrefs.py` only counts accesses. |
| `dosdis16.py` | Prints a 16-bit disassembly window of a DOS Gold Box image by file offset, backing up until an instruction boundary lands on the offset; `--strings` lists the printable runs matching a regex with their offsets. |
| `dosdisk.py` | Builds a C64 save disk from a DOS save folder with no existing save to copy, the command-line form of `File > Import`; needs the player's own `POOL` sides, and `--sheet` prints the DOS party laid out like the C64 `VIEW` screen. |
| `dosdropcensus.py` | Asks, one column at a time, whether any DOS record on this machine sets a field the conversion cannot yet convert, such as differing ability-pair bytes or memorised spell ids. Uses `dostailcensus.py`'s finder and prints a provenance caution on every run. |
| `dosencrecompute.py` | Finds in the shipped DOS binaries where the engine rewrites a stored encumbrance: `routine` finds the recompute function, `callers` its callers and money writers, `helpers` the two leaves that adjust the total by what a pool or give screen moved, `bags` every record with a bag of holding, `stock` every item the game's own tables can hand out that carries the word. Compare `dosencsave.py` and `tools/records/enccensus.py`. |
| `dosencsave.py` | Finds which screen makes DOS Pool of Radiance rewrite a stored encumbrance, writing a spoiled value into the file before the boot and taking up to three saves per boot; `--rungs` and `--boots` need no emulator. |
| `dosencumbrance.py` | Weighs a DOS character against the encumbrance the record stores, printing `money + sum(weight x quantity)` coin by coin and item by item; `--census` sweeps every `.SAV` and `.CHA` on the machine and reports how the discrepancy is distributed. |
| `dosfieldrefs.py` | Scans a DOSBox-X memory image for every instruction that reaches a character-record offset through an `ES` far pointer, split into reads and writes. A count is an upper bound, since nothing checks that a match is an instruction and not data. |
| `dosfightrun.py` | Drives a DOS Pool of Radiance fight to its end: `capture` presses a key ladder and logs command-bar digests, PNGs and save files, `fight` is the driver, and experience rising in `CHRDAT<slot><n>.SAV` is the ground truth. Writes under `<tmp>/wish/dosfightrun/`. |
| `dosfightwatch.py` | Watches a converted party's `WRITE_UNSOURCED` bytes through a DOS fight in DOSBox-X: `locate` finds each live record, `watch` arms a `BPM` per field and logs each write with `CS:IP`, `truth` has the game author the party. The party must be where wandering encounters happen. |
| `dosframeaudit.py` | Counts the DOSBox-X captures that are not a clean 2x2 replication, over several hundred unhalved `dosbox.Session.capture` frames taken while the viewport redraws, and reports how many blocks were ragged and where. |
| `dosgnome.py` | Rolls a character in DOS Pool of Radiance's CREATE NEW CHARACTER screens under DOSBox and dumps the `.SPC` effect records the engine writes; `--interactive` runs step lines appended to a command file so one boot maps many menus. |
| `dositemcap.py` | Tests DOS Pool of Radiance's sixteen-item ceiling in the running game: installs a specimen party, gives characters item lists of chosen lengths (`--counts`), and runs step lines in `dosgnome.py`'s vocabulary plus `@key`, which shoots with no settle. |
| `dosladder.py` | Climbs a DOS Pool of Radiance party a level at a time through the game's four training schools, one boot per level, keeping every record the trainer writes and re-staging experience and gold between rungs as inputs. |
| `dosmodifyprobe.py` | Watches DOS Pool of Radiance write the treasure-share byte at record `0x085` when KEEP is pressed: one boot rolls two characters and saves untouched, after MODIFY then EXIT, and after MODIFY then KEEP, with the second character as the control. |
| `dosnewsave.py` | Builds a DOS Pool of Radiance saved game from a C64 save disk with no template, boots it, reads the party off the game's screens, walks it (`--steps`) and has `ENCAMP > SAVE` write it back to diff against ours. The game tree is staged, so archives stay read only. |
| `dosoutdoor.py` | Makes an engine-written DOS Pool of Radiance save on the overland travel grid: seeds a copy of an indoor save onto a travel window, boots it, walks (`--steps`) and has `ENCAMP > SAVE` write the specimen, keeping the seed beside it named as a seed. |
| `dosoutdoorprobe.py` | Drives a party on the DOS travel grid: seeds an indoor save onto a travel window with a chosen wallset triple (`--wallset keep` leaves it alone), walks a scripted arrow route and takes `ENCAMP > SAVE` at each waypoint. |
| `dosovrmap.py` | Maps the overlay units out of the expanded `START.EXE` (`units`), resolves a far call to a `GAME.OVR` offset (`resolve`), disassembles from the nearest `55 89 E5` prologue (`dis`) and lists a routine's callers with their argument pushes (`callers`). Needs `capstone`. |
| `dosovrwindow.py` | Disassembles a window of a 16-bit DOS overlay around one or more file offsets, marking each; takes an overlay file or a title, hexadecimal offsets and byte counts either side. Needs `capstone`; read only. |
| `dosparty.py` | Rolls a whole DOS Pool of Radiance party in the game's own creation screens under DOSBox and saves it with SAVE CURRENT GAME, emptying the shipped roster first, then checks every record the engine wrote against the spec. |
| `dospod.py` | Drives DOS Pools of Darkness under DOSBox and snapshots its `SAVE` directory (`START.BAT`, `SAVGAM<slot>.PTY`, `VAULT<slot>.DAT`); steps are keysyms, `@x,y` clicks or `!name` snapshots. Archives are opened read only. |
| `dospodlevels.py` | Reads Pools of Darkness' level tables out of its DOS engine for `goldbox/levels.py`: `tables` the experience thresholds, THAC0 and saving-throw rows, attack bands, hit dice and constitution bonus, each located by the instruction that indexes it; `check` recomputes THAC0, saves and attacks for the records under the install's `SAVE` directory. |
| `dospodtables.py` | Reads Pools of Darkness' own tables out of its DOS engine: `slots` the four per-class slot progressions with the wisdom and intelligence gates, `spells` every spell id's class and level, `menus` the race, class and alignment lists, both ability-limit tables and the name-entry length. Every table offset comes from the instruction that indexes it. |
| `dosptrfields.py` | Lists the structure offsets reached through one global far pointer, which reads a DOS heap block's field map without a symbol table; a linear disassembly of a file that is not all code, so `--sites` prints where each hit came from. |
| `dosquickprobe.py` | Tests what DOS character-record `0x10F` does by its effect: stages a value into all six records, walks to a wandering encounter, and drives the fight with a key ladder that answers every screen except the combat command bar, counting what it is shown. |
| `dosraces.py` | Reads each DOS title's race-name table from its executable by walking back from `Lawful Good` through counted strings; `--check` compares it with the table in `goldbox/dos_port.py` and exits nonzero on a difference. Covers Pool of Radiance, Curse, Silver Blades and Pools of Darkness only. |
| `dosracialseed.py` | Reads DOS Pool of Radiance's character-creation switch out of `GAME.OVR`, race byte to the `add_affect` calls it pushes, and follows an effect id into its handler, finding both by structure and not by address. `tests/dos/test_dosracialseed.py` pins its reading. |
| `dosrecordloops.py` | Finds what walks an array inside a DOS character record, per instruction: ties the loop bound to the stack slot added into `di`, tells 0-based loops from 1-based ones, and prints the span covered. Reads the player's archives through `dosbox.find_game`; writes nothing. |
| `dosrecordwrite.py` | Writes DOS character records for every title `goldbox.dos_codec` can write and checks them: `roundtrip` writes each record back and reports what moved by field, `from-c64` converts a C64 save disk, `loop` compares a C64 save the game wrote with its source records. Writes only under `--out`. |
| `dossavcensus.py` | Censuses every DOS saved game on the machine by container size, deduplicated on bytes, leaving out hand-built seeds and parties saved before setting out (`--include-never-adventured` restores them), and reports which ECL variables are live (`--title`). |
| `dossavewritemap.py` | Reads a title's saved-game map from the engine's own save routine, following the chain of `BlockWrite` calls whose widths add up to a known container size; `--check` exits nonzero when a map and a `DosContainer` disagree. |
| `dossavgam.py` | Surveys every DOS saved-game container on the machine: region map, party table, party size and the variables that agree with the header byte. `--runs` prints runs of nonzero bytes before the party table, `--scripts` the largest `ECL<n>.DAX` block per title. Read only. |
| `dosscrollbundle.py` | Reads the four bytes at `0x03F`-`0x042` of a Silver Blades item as a far pointer to another item node: `sites` is the evidence, `walk` the engine's item-file loop, `census` sweeps for files that need it, `read` prints one pack. Read only; `docs/215-the-dos-experience-award-and-the-scroll-bundle.md`. |
| `dossheetread.py` | Loads a converted DOS party in the running game and photographs a sheet per character; `--resave`, `--save`, `--walk`, `--engine-save`, `--move-mode` and the `--pick-*` options resave, install a whole save, walk, and drive Silver Blades' highlight menu. Archives are read only. |
| `dosshop.py` | Walks a DOS Pool of Radiance party into one of New Phlan's four shops and buys on the game's BUY screen; `--map` re-derives the shop squares from the player's files with no emulator, `--encumbrance` spoils the stored field before the boot. |
| `dossideprobe.py` | Tests what the DOS engine does with a party member whose record byte `0x10E` (combat side, 0 party, 1 enemy) is 1: stages it with quickfight on all six, walks the Slums to an encounter, photographs the fight and reads the resave back. |
| `dosslotwatch.py` | `tools/curse_of_the_azure_bonds/doscurse.py`'s console over DOSBox-X with the debugger added: `find` party records and their spell-slot blocks, `poke`, `arm`, `armaddr`, `reboot`, and `collect` every watchpoint hit with `CS:IP`. Stages a patched save, since a `BPM` fires only on change. |
| `dosspcexpiry.py` | Puts the `.SPC` permanence rule to the running DOS game under DOSBox-X: `chain` reads every party member's effect chain off the heap before and after the clock moves, `ready` stages an item effect and reads what READY appends. `docs/162-spc-permanence.md`. |
| `dosspellslots.py` | Reads a DOS title's spell-slot block out of its own engine: the `FillChar` sites that zero it, a census of the spell table's class byte, references over the block, and `tables`, the per-class slot rows from the builder's delta tables. Finds nothing by a committed address. |
| `dostailcensus.py` | Censuses one field of the DOS character record over every `CHRDAT<slot><n>.SAV`, `.CHA` and `.GUY` on the machine, deduplicated on record bytes, printing the value partition with the characters holding each. Skips records we wrote, staged trees and Gateway or Treasures records unless `--foreign`. |
| `dostailprobe.py` | Asks whether the DOS engine keeps, shows or recomputes a record field: stages one value per party member in a real save, loads it, photographs party panel and sheet, and takes `ENCAMP > SAVE` back, with one character as the control. `--field` and `--pattern` choose the field. |
| `dosthiefgate.py` | Reads out of DOS Pool of Radiance's `GAME.OVR` which byte gates a thief's abilities, finding each site by its structure: the backstab predicate and its damage multiplier, the party-wide class test behind the locked door's `Pick` and `Knock` entries, the pick-lock roll against record `0x078`, the ECL aggregate over `0x079`, and every instruction that touches `class_bits`. `--check` exits nonzero if a reading is missing. `docs/221-thief-abilities-in-dos-pool-of-radiance.md`. |
| `dostrain.py` | Drives the DOS training hall: puts the party one step from its door, walks in, trains, and snapshots `SAVE/` before and after so a level-up can be diffed across the 285-byte record. |
| `dostrainprobe.py` | Tests whether Pool of Radiance gates TRAIN CHARACTER on the word at `0xD51` of `SAVGAM<slot>.DAT` by loading one save twice with only that word different; also installs a specimen party into a staged game with experience, gold and the gate set. |
| `dosvmwatch.py` | Watches the DOS engine write one ECL VM variable under DOSBox-X and names the instruction: stages a save, finds the live VM array, arms a `BPM` on a word, presses a key and records each change with `CS:IP`. `docs/163-dos-vm-address-map.md`. |
| `dosxpaward.py` | Names the unattributed run before a DOS record's portrait as an experience award and a per-hit-point award: `sites` prints the evidence, `monsters` reads `MON<n>CHA.DAX`, `census` sweeps every record for a non-zero award. `docs/215-the-dos-experience-award-and-the-scroll-bundle.md`. |
| `dualclassdos.py` | Shows where DOS keeps a dual-classed human's old class: `census` prints both level arrays and the byte after `level` for every DOS record on the machine, `code` counts who writes the former array in each title's `GAME.OVR`. |
| `dualclassregain.py` | Reads out of the overlays how each DOS engine decides a dual-classed human has regained his old class, and checks it against every record: `code` finds the `class_bits` rebuild, `census` predicts the mask. `docs/209-the-regained-dual-class-on-dos.md`. |
| `innateids.py` | Traces where a DOS innate effect id comes from: `seed` reads the race and class switches and their `add_affect` arguments out of `GAME.OVR`, `--ids` names every call site pushing an id, `census` lists every record with its effect file graded `spec`, `ours` or `found`. Read only. |
| `neveradventured.py` | Finds which DOS saved games on this machine were made from the party-formation menu before `BEGIN ADVENTURING`, across the three word-array titles, by `--by buffer` (the staged area script) or `--by word` (`$4FE1`). Never writes a saved game. |
| `ssbimport.py` | Brings one DOS Curse character into DOS Silver Blades through `ADD CHARACTER TO PARTY > CURSE` under DOSBox, with `--former-class` written at Curse `0x0F9` first, and saves after the import, after a rest and after trying his CURE, decoding `paladin_cures` and the `.SFX` effect ids at each; `docs/229-the-npc-window-bytes.md`. |
| `unexepack.py` | Expands a Microsoft EXEPACK-compressed DOS executable to its load image with relocations unapplied, so `seg:off` in the image is `seg*16+off`; DOS Pool of Radiance's `START.EXE` is packed this way. `docs/162-spc-permanence.md` reads from it. |
