# secret_of_the_silver_blades

Scripts for Secret of the Silver Blades: staging, loading, training and comparing its saves.

| file | purpose |
|---|---|
| `ssbarm16fight.py` | Variant of `ssbarm16quick.py` that drives the assassin fight with `melee_turn` on a 90 second watch and a 300 second budget, after the same teleport and step onto 15,12. Claims a pool slot; writes under the scratch directory. |
| `ssbarm16quick.py` | Teleports the position triple to Silver Blades 15,11, steps onto 15,12 to run `ECL10` arm 16, and drives the assassin fight with the game's `QUICK` command. Claims a pool slot; writes under the scratch directory. |
| `ssbarm2route.py` | Static, no emulator: lists `ECL10`'s arm 2 (the 14,11 shop) statements with strings shown as lengths, then prints `GEO10`'s attribute grid and searches for a route to 15,12 that never enters 14,11. Takes `--from`, `--to` and `--also` address ranges and reads the Silver Blades disks and the walked engine-resave specimen. |
| `ssbdisk.py` | Builds a Silver Blades C64 save disk from a DOS save folder, as `tools/dos/dosdisk.py` and `tools/curse_of_the_azure_bonds/cursedisk.py` do for the other two titles: this title's container is one 7424-byte `SAVEDBASH` at `$4B00` with three header rows unlike theirs. `--sheet` prints the DOS party as the C64 `VIEW` screen lays it out; `--check-areas` re-derives the 22 area rows off the player's disks and diffs them against `goldbox/areas.py`. |
| `ssbedit.py` | Edits a Silver Blades save in Wish and reads the edits off the game's own screens. `stage` changes a named character's name, gold and strength through `EditorBinding` and `editor.files.save_disk`, and reports each field before and after with the `+$C00` name table; `run` claims a pooled slot, stages the six sides through `ssbwarp.py`, loads the party and photographs the party-formation panel and the character sheet, one JSON line per event. `name_table` lifts the 16-byte-per-entry table from a payload and `table_index` says which entry belongs to a slot. |
| `ssbloadescape.py` | The `ssb15` boot with a single Escape sent once `ECL10` starts loading, to test whether Escape aborts the KERNAL load; counterpart of `ssbloadnoescape.py`. Claims a pool slot; writes under the scratch directory. |
| `ssbloadnoescape.py` | The `ssb14` boot with no Escape ever sent, polling slot 8's KERNAL end address and `ECL10`'s tail to see whether the script then loads whole; counterpart of `ssbloadescape.py`. Claims a pool slot; writes under the scratch directory. |
| `ssbloadwatch.py` | Arms a non-stopping store checkpoint over `$9AC8`-`$9B64` at the Silver Blades party menu, before `LOAD SAVED GAME`, and dumps `$8000`-`$9FFF` plus the loader tables at the menu, after the load and at the world bar, to find what writes the tail of `ECL10`. Claims a pool slot and boots the walked engine-resave specimen from `$WISH_SPECIMENS`; writes under the scratch directory. |
| `ssbresavewalk.py` | Drives a converted Silver Blades C64 save disk in VICE through `ssbwarp.SSBSession`: loads the party, arrives, reads one sheet by pressing VIEW and reading the raw screen, walks one square and lets the engine's own ENCAMP > SAVE resave. Keeps screenshots, a JSON-lines log, `summary.json` and the resaved disk. Claims one pool slot; `--disks`, `--produced` and `--out` as arguments. |
| `ssbreturnprobe.py` | Repeats the `ssbstep1512.py` setup, then sends one KERNAL Return once the message is on screen and reads the interpreter state before and after, driving a fight if the mode byte reaches combat. Claims a pool slot; writes under the scratch directory. |
| `ssbrevalidate.py` | Walks to Silver Blades 15,11 then 15,12 and checks `in_combat()`, driving a fight with `Session.fight()` if one starts, to confirm `enter_world`'s Escape handling does not abort a slow mid-load ECL script. Claims a pool slot; writes under the scratch directory. |
| `ssbrun.py` | A driven Silver Blades session on a pooled VICE instance, with a save disk this project built staged as `SIDE0` and the session left serving for `tools/c64/porcmd`. The boot is `ssbwarp.py`'s, so this file adds only the save disk and the serve. |
| `ssbsavediff.py` | Diffs two `SAVEDBASH` payloads region by region and says whose each differing byte is, so the engine's own ENCAMP > SAVE can be used as the oracle a conversion is checked against. Its region table differs from `tools/curse_of_the_azure_bonds/cursesavediff.py`'s because five header rows change hands between the titles. Exits non-zero while any run lands in a region a conversion writes. |
| `ssbstage.py` | Copies a Silver Blades save and sets `$4C2D` (`SAVEDBASH`'s load address `$4B00` plus file offset `$12D`) to 1, the wandering-encounter roll's fight-or-compliment gate, which is off in every specimen. Nothing else in the save is touched, and the input is opened read only. |
| `ssbstep1512.py` | Stages the party at Silver Blades 15,11, takes one step onto 15,12 and reads eleven addresses at +0, +5, +15, +30 and +60 seconds, with a watchpoint on `$4C05`. Claims a pool slot; writes readings and dumps under the scratch directory. |
| `ssbtailprobe.py` | Reads block 28 of `ECL10` (`$9AC8`-`$9B64`) at the Silver Blades world bar, at 15,11 and at 15,12, with a store checkpoint armed between the first two readings. Claims a pool slot; writes under the scratch directory. |
| `ssbtrain.py` | Stages a Silver Blades save disk with experience, platinum, constitution, race, class bits, dual-class pair, rolled hit points and per-class levels written into named slots, boots it on a pooled VICE instance through `ssbrun.py`, and diffs a before and after record, checking the five stored saving throws against `goldbox.levels.saving_throws` first and then whatever `goldbox.levelup.plan` can reproduce. Poking `$7EA8` to 127 opens the training hall wherever the party stands, as in `tools/curse_of_the_azure_bonds/cursetrain.py`; a slot is found by the name inside the record, since the `+$C00` name table runs in marching order. |
| `ssbtrainerinputs.py` | Reads off the player's disks the three trainer inputs Silver Blades' entry in `goldbox/levels.py` still lacks (`hp_bonus_by_score`, `thief_skills` with `thief_skill_race`, and `wisdom_bonus_level`), prints them, and checks each against the same table in Curse's files and against a character the game itself wrote. Nothing is transcribed into the repository; `--rows` prints what each race code gets from the thief's racial row, which the game reads one row too far. |
| `ssbtwins.py` | Converts the six DOS characters SSI shipped and diffs each against the C64 record SSI shipped for the same character, field by field. A consistency check rather than proof, since neither side has a chain of custody. |
| `ssbwarp.py` | Fast-travels a running Silver Blades party on a pooled slot, to turn `goldbox.areas.AREAS_SILVER_BLADES`' rows into measurements: stages the six sides, boots, loads a party, hands each target to `automap.actions.FastTravel`, then reads back the cache slot, the disk byte, the live square and the 1024 bytes at `$0400`. `--to` takes a comma-separated chain driven in one boot; `--spoil-from N` writes a square no row carries in front of a hop. It handles the cracker intro, the fastloader prompt that comes after it, and the loader's lettered sides, which `tools/c64/session.py` does not. |
