wish
====

`wish <https://github.com/malcyon/wish>`_ is a character editor, save editor
and live automapper for the Commodore 64 Gold Box games, built by reverse
engineering.

Two halves. The **API reference** is generated from the source's own
docstrings. The **knowledge base** is hand-written: the reverse-engineering
notes the code rests on, and the reason most of it is shaped the way it is.
